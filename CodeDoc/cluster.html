Clusters creation

The following functions build clusters from a variety of inputs. of_edgelist is the most useful for creating seeds from scratch. The other functions are useful when modifying existing seeds in nonstandard ways

val of_edgelist : graph:(Vertex.t * Vertex.t) list -> frozen:Vertex.Set.t -> cluster
let c = of_edgelist ~graph:[(vsource1,vtarget1);...;(vsourceN,vtargetN)] ~frozen:(Vertex.Set.of_list [f1;f2;...;fN])

produces a seed for a cluster algebra with arrows given by the list in graph

The set vertices in the set passed to frozen are frozen, while all others are mutable.

High weight edges are given by repeating arrows between the same vertices. Including both (u,v) and (v,u) in graph will result in no arrows between u and v

val of_nbrlist : graph:(Vertex.t * (Vertex.t list * Vertex.t list)) list -> frozen:Vertex.Set.t -> cluster
val of_list : graph:(Vertex.t * int Vertex.Map.t) list -> frozen:Vertex.Set.t -> cluster
val of_quiver : quiver:nbrs Vertex.Map.t -> frozen:Vertex.Set.t -> cluster

Modifying Seeds

val freeze : t -> Vertex.t list -> t
 let c2 = freeze c1 [v1;...;vn]

returns a seed where vertices v1,...,vn are considered frozen.

 let c3 = unfreeze c2 [v1;...;vn]

returns a seed where vertices v1,...,vn are mutable.

val unfreeze : t -> Vertex.t list -> t
 let c3 = unfreeze c2 [v1;...;vn]

returns a seed where vertices v1,...,vn are mutable.

After the previous two commands, c1 = c3.

If vi was not alread a vertex of c it is added without any arrows to the seed

val removeFrozen : cluster -> cluster

removeFrozen c returns a seed with the frozen nodes removed. This is sometimes useful for making nice pictures.

WARNING: Using the seed returned from removeFrozen will not function correctly in general

val rev : cluster -> cluster

Returns a cluster with every arrow pointing in the opposite direction

val map : cluster -> f:(Vertex.t -> Vertex.t) -> cluster

map c ~f:f returns a new seed where f is applied to each cluster variable. Requires: f to be injective on the cluster variables in the seed to result in a new seed Warning: Unless f is chosen carefully mutation in the new seed might not make sense

val matrix : ?vorder:Vertex.t list Core.Option.t -> cluster -> int list list

Returns the adjaceny matrix for c

 let m = matrix ~vorder:(Some [v1;...;vn]) c

returns a nxn list of list of integers where the entry (i+1,j+1) is the number of arrows from vi to vj

If no vorder is given, the vertices are sorted by unfrozen and then frozen

Dimension of cluster algebra (number of mutable nodes)

C-vectors

val cVector : ?frozenlist:Vertex.t list option -> cluster -> Vertex.t -> int list
let l = cVector ~frozenList:(Some vs) c u

returns l whose ith entry is the number of arrows from the vi to u where vi is the ith entry of vs

If ~frozenList is not provided a default ordering on the frozen vertices is chosen.

val cVectors : ?frozenlist:Vertex.t list option -> cluster -> int list list
 let cvecs = cVectors ~frozenList:(Some vs) c

returns a list of c-vectors obtained by calling cVector for each mutable vertex.

The c-vectors are sorted lexographically to give an order independent of the ordering of the mutable vertices

Degrees of nodes

val sources : cluster -> Vertex.Set.t

sources c returns the set of mutable vertices with only out arrows

val sinks : cluster -> Vertex.Set.t

sinks c returns the set of mutable vertices with only in arrows

val sources_sinks_neithers : cluster -> Vertex.Set.t * Vertex.Set.t * Vertex.Set.t
let (source,sink,neither) = sources_sinks_neithers c

partions the mutable vertices of c into three sets depending if they have only out neighbors, in neigbhors or both

val oNbr : ?frozen:bool -> cluster -> Vertex.t -> int Vertex.Map.t

oNbr c v returns a map whose keys are out neigbors (mutable and frozen) of v in c and data is the number of arrows. oNbr ~frozen:false c v only returns mutable neighbors of v

val iNbr : ?frozen:bool -> cluster -> Vertex.t -> int Vertex.Map.t

iNbr ~frozen:include_frozen c v returns a map whose keys are in neigbors of v in c and data is the number of arrows Note that the weights in the output are negative reflecting the fact the arrows are into v

val nbrSet : ?frozen:bool -> cluster -> Vertex.t -> Vertex.Set.t

nbrSet ~frozen:include_frozen c v returns the set of neigbors of v in c. The weight of the arrows is lost

val oNbrSet : ?frozen:bool -> cluster -> Vertex.t -> Vertex.Set.t

oNbrSet ~frozen:include_frozen c v returns the set of out neigbors of v in c. The weight of the arrows is lost

val iNbrSet : ?frozen:bool -> cluster -> Vertex.t -> Vertex.Set.t

iNbrSet ~frozen:include_frozen c v returns the set of in neigbors of v in c. The weight of the arrows is lost

val nbrList : ?frozen:bool -> cluster -> Vertex.t -> Vertex.t list

nbrList ~frozen:include_frozen c v returns a list of neigbors of v in c. Multi arrow neighbors are listed |weight| many times.

val oNbrList : ?frozen:bool -> cluster -> Vertex.t -> Vertex.t list

oNbrList ~frozen:include_frozen c v returns a list of out neigbors of v in c. Multi arrow neighbors are listed |weight| many times.

val iNbrList : ?frozen:bool -> cluster -> Vertex.t -> Vertex.t list

iNbrList ~frozen:include_frozen c v returns a list of in neigbors of v in c. Multi arrow neighbors are listed |weight| many times.

val edge_weight : cluster -> inp:Vertex.t -> out:Vertex.t -> int

edge_weight c ~inp:vin ~out:vout = w where w is the weight of the arrow between vin and vout in c

val iDegree : ?frozen:bool -> cluster -> Vertex.t -> int

iDegree c v returns -1*(the number of in neighbors of v in c) each edge (vin,v,weight) is counted weight many times so iDegree c v = -1*List.length(iNbrlist c v) The default value for ~frozen is true and counts arrows from frozen nodes

val oDegree : ?frozen:bool -> cluster -> Vertex.t -> int

the same as iDegree but for out edges, the returned value is positive

val degree : ?frozen:bool -> cluster -> Vertex.t -> int * int
degree c v = (oDegree c v, iDegree c v)
val valence : ?frozen:bool -> cluster -> Vertex.t -> int

Total number of in/out edges from c valence c v = Int.abs(iDegree c v) + oDegree c v

Predefined Cluster Properties

val is_SourceSink : cluster -> bool

is_SourceSink c returns true iff and only if every mutable node is either a source or a sink

val is_acylic : cluster -> bool

is_acylic c returns true if c has no directed cycles (in mutable part)

val fAffineDynkin : cluster -> bool

Returns true if each component of the quiver is one of:

  • acylic quiver with each node a sources/sink, # sources >= #sinks
  • unoriented cylce with exactly one source and sink These quivers can be used to easily identify the type of a finite/affine algebra
val is_Tpqr : cluster -> bool

is_Tpqr c returns true if c

  • contains a single double edge (u,v,2)
  • each neighbor w of u is an out neighbor and also an in neigbhor of v (u,v,w is a an oriented cycles
  • the quiver without u is orriented so every node is a source or a sink WARNING This isn't exactly the same as being a Tpqr quiver as in cluster modular group paper
val dynkin_type : cluster -> string

REQUIRES: fAffineDynkin c = true or is_Tpqr c = true * returns string identifying the kind of cluster

val is_fork : cluster -> Vertex.t option

Returns Some r if c is a fork with point of return r and None otherwise A fork is a quiver with the following properties:

  1. Every edge is weight >=2
  2. for each path of edges i -> r -> j have edge_weigth c ~inp:j ~out:i > edge_weight c ~inp:i ~out:r and edge_weight c ~inp:j ~out:i > edge_weight c ~inp:r ~out:j
  3. the full subquiver of nodes into r is acylic
  4. the full subquiver of nodes out of r is acyclic
val is_key : cluster -> (Vertex.t * Vertex.t) option

Returns Some (k,k') if c is a key with vertices k and k' such that

  • Q-k and Q-k' are both abundant acylic
  • For each i in Q-{k,k'} either
  1. k->i and k'->i
  2. i->k and i->k'
val is_prefork : cluster -> (Vertex.t * (Vertex.t * Vertex.t)) option

is_prefork c == Some(r,(k,k')) if c is a prefork such that

  • Q-k and Q-k' are forks with common point of return r

  • For each i in Q-{k,k'} either

    • k->i and k'->i
    • i->k and i->k'
val fEdgeAbove : ?frozen:bool -> cluster -> w:int -> bool

fEdgeAbove c w returns true is there is an edge above weight w in c the default value of ~frozen is true and includes edges to and between frozen nodes

val is_abundant : cluster -> bool

A quiver is abundant if every edge has weight at least 2

val fCVectorAbove : ?frozenlist:Vertex.t list option -> cluster -> w:int -> bool

fVectorAbove c ~w:weight returns true if and only if there is an edge between a frozen node and mutable node with weight at least weight.

Mutation

val mutate : cluster -> Vertex.t -> cluster

let (c',w) = mutate_name c v results in a seed c' by mutating in the direction of v, and w replaces v since mutation is an involution: mutate_name c' w = (c,v)

val mutate_name : cluster -> Vertex.t -> cluster * Vertex.t
val mutate_multi : cluster -> Vertex.t list -> cluster

let (c',path_back) = mutate_multi_name (c,path) mutates at v1 then v2 then ... vn where path = [v1;v2;...vn] and returns the final seed c' and path_back where path_back is the list vertices needed to mutate at to return to c from c'.

mutate_multi c' path_back == (c,path)
val mutate_multi_name : cluster -> Vertex.t list -> cluster * Vertex.t list
